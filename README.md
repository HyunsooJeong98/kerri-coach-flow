# KERRI Coach Platform

러버블(Lovable) 프롬프트 — KERRI 홈페이지 (최종본)

아래 내용을 그대로 러버블에 붙여넣어 랜딩페이지를 생성해줘.

한국의 개인 레슨 코치를 위한 운영 플랫폼 **KERRI(케리)**의 랜딩 페이지를 만들어줘.

방문자는 테니스, 골프, PT, 필라테스, 배드민턴 등 개인 레슨 코치이며, 목표는 코치앱 다운로드 및 무료 체험 시작이다.

모든 텍스트는 한국어로 작성한다.
